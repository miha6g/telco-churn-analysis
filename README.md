# Анализ оттока клиентов телеком-компании

## Описание

Проект посвящён анализу факторов, влияющих на отток клиентов телеком-компании.  
Цель — выявить основные причины ухода клиентов и сформулировать рекомендации по снижению оттока.

## Данные

Использован открытый датасет Telco Customer Churn (Kaggle).  
Содержит информацию о ~7000 клиентах: демография, услуги, тип контракта, платежи и факт оттока.

## Основные выводы

- Наибольший отток у клиентов с **помесячным контрактом** (Month-to-month)
- **Новые клиенты** (tenure < 12 месяцев) уходят значительно чаще
- Клиенты с **Fiber optic** имеют более высокий отток, чем клиенты с DSL
- Оплата через **Electronic check** связана с повышенным оттоком
- Наблюдается рост оттока при увеличении ежемесячного платежа

## Рекомендации

- Стимулировать переход на долгосрочные контракты
- Усилить сопровождение новых клиентов в первые месяцы
- Проанализировать причины оттока среди пользователей Fiber optic
